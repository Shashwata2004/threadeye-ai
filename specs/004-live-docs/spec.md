# Live /docs Module

Created: 2026-11-21

Public /docs combines editable bilingual pitch sections, technical/data-flow
diagrams, stack and live API inventory, aggregate operational statistics, model
card evidence, DU_Synapse team contacts and the supplied presentation video.
Admin settings permission controls content, sections, team and resized images,
publication and optional timezone-aware start/end. Hidden/outside-window public
requests return 404, including live data; admins have a private preview.

No arbitrary HTML, raw user records, inspection identifiers, audit contents,
credentials or arbitrary external images are published. Published live aggregates
are refreshed every 15 seconds; authored narrative is separately labeled.

Acceptance: publishing OFF/ON/window, endpoint RBAC, persistent edits, concurrent
edit conflict, valid/invalid images and links, team edits, live count changes,
API discovery, diagrams, localized mobile layout and public non-caching behavior.
