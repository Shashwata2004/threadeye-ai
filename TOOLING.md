# Tooling, IDE, memory/context files and MCP disclosure

This covers the **Tooling + IDE + memory/context files** and **MCP usage** submission sections.
AI-assisted coding is allowed and is disclosed in full. Update this file whenever a tool is added.

## AI coding assistants
| Tool | Model | Used for | Since |
|---|---|---|---|
| Claude Code, desktop app (Code tab) | Claude Opus 5.5 (`claude-opus-5-5`) | Plan mode for the build plan (`docs/PLAN.md`); M0 scaffolding (backend, frontend, Docker, CI, docs) | 2026-10-03 |

Every prompt is recorded in [PROMPTS.md](PROMPTS.md). Code produced with AI help is reviewed by a team member before merge (PR review rule, PLAN.md §10).

## Memory / context files
| File | Location | Purpose |
|---|---|---|
| `CLAUDE.md` | repo root (committed) | Project memory for AI assistants: product summary, honesty rules, conventions, commands |
| Claude Code auto-memory | `~/.claude/projects/<project>/memory/` on the developer's machine (**not** committed) | Assistant-maintained notes across sessions. Content is disclosed on request. |
| Plan file | `~/.claude/plans/serene-launching-toast.md` (local), copied to `docs/PLAN.md` | Plan-mode output |
| `frontend/AGENTS.md` + `frontend/CLAUDE.md` | committed; generated by `create-next-app` 16 and kept by `next dev` | Tells AI coding agents to read the bundled Next.js 16 docs (`node_modules/next/dist/docs/`) before writing code |
